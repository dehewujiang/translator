# 翻译小助手（用户视角）

常驻后台的 Windows 翻译弹窗：复制内容点一下 `Ctrl` 出译文。英文进 → 出中文（单词出词典）；中文进 → 出英文。界面里能分别调两个方向的翻译要求。

## 已完成

- 中文也能翻：原文框或剪贴板里是中文，就翻成英文；中英混在一起按中文算。纯英文走原来的路，查单词仍出词典。
- 中译英的翻译要求能改了：配置窗多一个「中译英要求（中文进、英文出）」框，跟英译中那条并排，留空就用默认。改一边不影响另一边。
- 配置窗矮屏不挤：窗口不够高时先自动收两个提示词框的行数，新框不会被挤出可视区，底下按钮也不会被裁。
- 高分屏不再发虚：按系统缩放（这台是 125%）真正适配，字、图标、间距一起放大。
- 字和图标更清楚：浅灰标签、工具图标都加深到看得清；齿轮颜色与其它图标统一。
- 译文区只读：能选中复制，不会被误打字改坏。
- 词典查词：英音、美音各占一行，不会把"美"和音标拆成两行。
- 配置窗：锁定尺寸、标题栏是蓝底"译"、删除先确认、关掉时提醒未保存、列表用 ✓+蓝字标"正在用"。
- 图标间距拉开，复制与关闭不易误点；悬停提示不再 1.5 秒自己消失。
- 窗口可拖底边调高矮，往上拖到底按钮不消失；图钉可钉住；拖过位置不弹回。
- P2 全部完成：配置窗可"测试连接"、钥匙可显示/隐藏；没内容时有引导；长译文右侧有细滚动条；英文用系统英文字体；左右边能拖宽；界面跟随系统深色模式。
- exe 上次重打是 P2 那轮（37.7MB）；本轮新功能还没打进 exe。
